# Chapter 03: Linear Equations in Two Variables (Class IX)

## Concept Summary

This chapter introduces equations in two variables:

1. **Recall**: Linear equations in one variable and their solutions.

2. **Introduction to Two Variables**: Focus on linear equations of the form `ax + by + c = 0`, where a, b, c are real numbers, and a and b are not both zero.

3. **Solutions as Ordered Pairs**: A solution is an ordered pair (x, y) of real numbers that satisfies the equation. A linear equation in two variables has infinitely many solutions.

4. **Geometric Interpretation**: Solutions when plotted as points in the Cartesian plane lie on a straight line. Every point on the line is a solution.

## Key Formulas/Theorems

**Standard Form**: ax + by + c = 0, where a, b, c are real and a, b are not both zero.

**Solution Form**: If we assign any value to one variable, the other variable is determined. For example, in ax + by + c = 0:
- For any x = k, y = -(ak + c)/b (when b != 0)

**Number of Solutions**: A linear equation in two variables has infinitely many solutions.
