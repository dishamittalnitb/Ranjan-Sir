# Chapter 27: Quadratic Equations (Class X)

## Concept Summary

This chapter studies quadratic equations and their solutions:

1. **Standard Form**: ax^2 + bx + c = 0, where a, b, c are real numbers and a != 0.

2. **Solution by Factorization**: Factor the quadratic expression as a product of two linear factors if possible, then set each to zero.

3. **Quadratic Formula**: 
   - x = [-b +/- sqrt(b^2 - 4ac)] / 2a
   - Discriminant D = b^2 - 4ac

4. **Nature of Roots** (based on discriminant):
   - D > 0: Two distinct real roots (roots are rational or irrational)
   - D = 0: Two equal real roots (one repeated root)
   - D < 0: No real roots

5. **Situational Problems**: Real-life problems modeled as quadratic equations (time-distance-speed, area, numbers, work-time).

## Key Formulas/Theorems

**Quadratic Formula**: x = [-b +/- sqrt(b^2 - 4ac)] / 2a

**Discriminant**: D = b^2 - 4ac

**Sum and Product of Roots** (for ax^2 + bx + c = 0 with roots alpha, beta):
- alpha + beta = -b/a
- alpha * beta = c/a

**Method of Completing the Square**: Write ax^2 + bx + c = a(x + b/2a)^2 - (D/4a)
