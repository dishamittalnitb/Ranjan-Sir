# Chapter 29: Coordinate Geometry (Class X)

## Concept Summary

This chapter develops formulas for computing distances and dividing line segments in the coordinate plane:

1. **Review**: Cartesian plane, plotting points, coordinates, quadrants (from Class IX).

2. **Distance Formula**: The distance between two points A(x1, y1) and B(x2, y2) is:
   - AB = sqrt[(x2 - x1)^2 + (y2 - y1)^2]
   - Derived from the Pythagorean Theorem.

3. **Section Formula** (Internal Division): The coordinates of a point P dividing the line segment joining A(x1, y1) and B(x2, y2) internally in the ratio m : n are:
   - P = [(m*x2 + n*x1)/(m + n), (m*y2 + n*y1)/(m + n)]

4. **Mid-Point Formula**: Special case of section formula with m = n = 1:
   - Mid-point = [(x1 + x2)/2, (y1 + y2)/2]

5. **Applications**: Verifying collinearity, proving geometric figures (triangle types, quadrilaterals), finding points.

## Key Formulas/Theorems

**Distance Formula**: d = sqrt[(x2 - x1)^2 + (y2 - y1)^2]

**Section Formula** (m : n internally): 
P(x, y) = ((m*x2 + n*x1)/(m + n), (m*y2 + n*y1)/(m + n))

**Mid-Point Formula**: Mid-point = ((x1 + x2)/2, (y1 + y2)/2)

**Collinearity Test**: Three points A, B, C are collinear if AB + BC = AC or if area of triangle ABC = 0.

**Centroid of Triangle** (with vertices (x1,y1), (x2,y2), (x3,y3)):
Centroid = ((x1 + x2 + x3)/3, (y1 + y2 + y3)/3)
