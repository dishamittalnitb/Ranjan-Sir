# Chapter 14: Coordinate Geometry Plotting [FORMATIVE ONLY]

## Concept Summary

This formative-only topic provides hands-on practice with plotting points in the Cartesian plane:

1. **Plotting Points**: Given coordinates (x, y), locate the corresponding point in the plane. Practice with integers, rational numbers.

2. **Reading Coordinates**: Given a point in the plane, determine its coordinates.

3. **Pattern Recognition**: Plot sets of points to observe patterns -- collinear points, vertices of geometric shapes (triangles, rectangles, squares).

4. **Applications**: 
   - Plotting data points from tables
   - Drawing geometric figures on the coordinate plane
   - Understanding symmetry through plotting

5. **Connection to Graphs**: Foundation for graphing linear equations (Ch13 formative topic).

## Key Formulas/Theorems

**Plotting a Point (x, y)**:
1. Start at origin (0, 0)
2. Move |x| units along x-axis (right if x > 0, left if x < 0)
3. Move |y| units parallel to y-axis (up if y > 0, down if y < 0)
4. Mark the point

**Quadrant Identification**:
- QI: x > 0, y > 0
- QII: x < 0, y > 0
- QIII: x < 0, y < 0
- QIV: x > 0, y < 0
