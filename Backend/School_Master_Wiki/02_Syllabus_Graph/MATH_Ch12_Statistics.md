# Chapter 12: Statistics (Class IX)

## Concept Summary

This chapter introduces statistical data representation:

1. **Data Collection**: Primary and secondary data. Presentation of data in tabular form, grouped and ungrouped.

2. **Bar Graphs**: Visual representation of categorical data using rectangular bars of uniform width with lengths proportional to the values they represent. Used for comparing discrete categories.

3. **Histograms**: Graphical representation of a grouped frequency distribution with continuous classes. Unlike bar graphs, histograms have no gaps between bars. Base width represents class interval; height represents frequency. Special case: histograms with varying base lengths (adjusting for unequal class intervals).

4. **Frequency Polygons**: A line graph representation of a frequency distribution. Obtained by joining the mid-points of the tops of histogram bars (or by plotting class-marks against frequencies). Can also be drawn independently without a histogram.

## Key Formulas/Theorems

**Class Mark** (for frequency polygon): (Upper Class Limit + Lower Class Limit) / 2

**Adjusted Frequency** (for histograms with unequal intervals): 
Adjusted Frequency = (Frequency / Class Width) * Minimum Class Width

**Frequency Polygon Construction**: 
- Plot points (class mark, frequency)
- Join with straight line segments
- Extend to zero frequency at both ends (anchoring)
