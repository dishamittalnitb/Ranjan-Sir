# Chapter 04: Structure of Atom

## 1. Concept Summary

### 1.1 Discovery of Sub-Atomic Particles
| Particle | Discoverer | Charge | Mass (approx.) | Location |
|----------|-----------|--------|----------------|----------|
| **Electron (e-)** | J.J. Thomson (cathode rays) | -1 (negative) | 9.1 x 10^-31 kg (~1/1840 of proton) | Outside nucleus |
| **Proton (p+)** | E. Goldstein (canal rays/anode rays) | +1 (positive) | 1.67 x 10^-27 kg (~1 u) | Inside nucleus |
| **Neutron (n)** | James Chadwick | 0 (neutral) | 1.67 x 10^-27 kg (~1 u) | Inside nucleus |

### 1.2 Atomic Models
| Model | Scientist | Key Points | Limitations |
|-------|-----------|------------|-------------|
| **Thomson's Model** | J.J. Thomson | Atom as a positively charged sphere with electrons embedded (plum pudding model). | Could not explain Rutherford's scattering experiment. |
| **Rutherford's Model** | Ernest Rutherford (alpha-particle scattering experiment) | Most of the atom is empty space; dense positively charged nucleus at centre; electrons revolve around nucleus. | Could not explain stability of atom (electron should spiral into nucleus per electromagnetic theory). |
| **Bohr's Model** | Niels Bohr | Electrons revolve in discrete (fixed) orbits/shells with fixed energy; no energy loss while in orbit; energy absorbed/emitted only when electron jumps between orbits. | Could not explain spectra of multi-electron atoms; could not explain Zeeman effect. |

### 1.3 Electronic Configuration
- Electrons are distributed in shells/orbits: K, L, M, N (n = 1, 2, 3, 4).
- **Maximum electrons in a shell:** 2n^2 (where n = shell number).
  - K shell (n=1): max 2 electrons
  - L shell (n=2): max 8 electrons
  - M shell (n=3): max 18 electrons (but as outermost shell, max 8)
  - N shell (n=4): max 32 electrons
- **Octet rule:** Atoms tend to have 8 electrons in their outermost shell (except H, He which need 2).

### 1.4 Valency
- The combining capacity of an element; determined by the number of electrons in the outermost shell.
- **Valency** = Number of electrons gained, lost, or shared to achieve noble gas configuration.
- For metals: Valency = Number of valence electrons (typically lose electrons).
- For non-metals: Valency = 8 - Number of valence electrons (typically gain electrons).

### 1.5 Atomic Number and Mass Number
| Term | Symbol | Definition |
|------|--------|------------|
| **Atomic Number** | Z | Number of protons in the nucleus. Determines the identity of the element. For neutral atom: no. of protons = no. of electrons. |
| **Mass Number** | A | Total number of protons and neutrons in the nucleus: A = Z + N (where N = number of neutrons). |
| **Notation** | ^A_ZX | E.g., ^12_6C, ^35_17Cl |

### 1.6 Isotopes and Isobars
| Term | Definition | Example |
|------|-----------|---------|
| **Isotopes** | Atoms of the same element having same atomic number (Z) but different mass number (A). Same chemical properties, different physical properties. | ^35_17Cl and ^37_17Cl; ^12_6C, ^13_6C, ^14_6C; ^1_1H, ^2_1H, ^3_1H |
| **Isobars** | Atoms of different elements having same mass number (A) but different atomic number (Z). Different chemical and physical properties. | ^40_18Ar and ^40_20Ca; ^14_6C and ^14_7N |

**Applications of Isotopes:**
- Uranium isotope (U-235) for nuclear fuel.
- Cobalt isotope (Co-60) for cancer treatment.
- Iodine isotope (I-131) for treatment of goitre.
- Carbon-14 for radioactive dating.

## 2. Key Formulas/Definitions

| Term | Formula / Relation |
|------|-------------------|
| **Mass Number (A)** | A = Z + N (Z = protons, N = neutrons) |
| **Maximum electrons in shell** | 2n^2 (n = shell number, n=1,2,3...) |
| **Valency (for metals)** | Number of valence electrons |
| **Valency (for non-metals)** | 8 - Number of valence electrons |
| **Isotopes** | Same Z, different A |
| **Isobars** | Same A, different Z |

## 3. Board Exam Weightage & Question Pattern

Falls under **Unit I: Matter - Its Nature and Behaviour (25 marks)**.

- **VSA (1 mark):** Define atomic number, mass number, isotopes, isobars, valency; identify particle by charge/mass.
- **SA (2-3 marks):** Draw Bohr's model for given element; calculate protons/neutrons/electrons; write electronic configuration; differentiate isotopes and isobars; applications of isotopes.
- **LA (5 marks):** Compare Rutherford and Bohr models; describe Rutherford's experiment with diagram; complete detailed electronic configuration.
- **Assertion-Reasoning:** Based on atomic structure, valency, isotope/isobar concepts.
