# Chapter 02: Polynomials (Class IX)

## Concept Summary

This chapter introduces and develops polynomial algebra:

1. **Definition**: A polynomial in one variable is an algebraic expression of the form p(x) = a_n*x^n + a_(n-1)*x^(n-1) + ... + a_1*x + a_0, where a_i are constants and n is a non-negative integer. Includes examples and counter-examples.

2. **Terminology**: Coefficients, terms, zero polynomial. Degree of a polynomial. Classification: constant (degree 0), linear (degree 1), quadratic (degree 2), cubic (degree 3). Monomials, binomials, trinomials. Factors and multiples.

3. **Zeroes of a Polynomial**: A real number 'a' is a zero of polynomial p(x) if p(a) = 0.

4. **Remainder Theorem**: If p(x) is divided by (x - a), the remainder is p(a).

5. **Factor Theorem**: (x - a) is a factor of p(x) if and only if p(a) = 0. Factorization of quadratic ax^2 + bx + c (a != 0) and cubic polynomials using the Factor Theorem.

6. **Algebraic Identities**: Verification and use in factorization of polynomials.

## Key Formulas/Theorems

**Remainder Theorem**: When p(x) is divided by (x - a), remainder = p(a).

**Factor Theorem**: (x - a) is a factor of p(x) iff p(a) = 0.

**Algebraic Identities**:
- (x + y + z)^2 = x^2 + y^2 + z^2 + 2xy + 2yz + 2zx
- (x + y)^3 = x^3 + y^3 + 3xy(x + y)
- (x - y)^3 = x^3 - y^3 - 3xy(x - y)
- x^3 + y^3 = (x + y)(x^2 - xy + y^2)
- x^3 - y^3 = (x - y)(x^2 + xy + y^2)
- x^3 + y^3 + z^3 - 3xyz = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)

**Classic Identities (Review)**:
- (a + b)^2 = a^2 + 2ab + b^2
- (a - b)^2 = a^2 - 2ab + b^2
- (a + b)(a - b) = a^2 - b^2
