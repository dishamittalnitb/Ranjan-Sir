# Chapter 38: Probability (Class X)

## Concept Summary

This chapter introduces the classical theory of probability:

1. **Classical Definition of Probability** (also called theoretical or a priori probability):
   - P(E) = (Number of outcomes favorable to event E) / (Total number of all possible outcomes of the experiment)
   - Assumes all outcomes are equally likely.

2. **Key Terms**:
   - **Experiment**: An action or trial with observable results
   - **Outcome**: A possible result of an experiment
   - **Event**: A set of one or more outcomes
   - **Sample Space**: The set of all possible outcomes
   - **Equally Likely Outcomes**: Outcomes with the same chance of occurrence
   - **Elementary Event**: An event with exactly one outcome

3. **Properties**:
   - 0 <= P(E) <= 1
   - P(Sure Event) = 1
   - P(Impossible Event) = 0
   - P(E) + P(not E) = 1, i.e., P(E-bar) = 1 - P(E)

4. **Typical Experiments**:
   - Tossing a coin (1 coin, 2 coins, 3 coins)
   - Throwing a die (1 die, 2 dice)
   - Drawing a card from a well-shuffled deck of 52 cards
   - Drawing balls/marbles from a bag

## Key Formulas/Theorems

**Classical Probability**: P(E) = n(E) / n(S)

**Complement Rule**: P(not E) = 1 - P(E)

**For a Deck of Cards** (52 cards):
- Red cards: 26 (13 hearts + 13 diamonds)
- Black cards: 26 (13 spades + 13 clubs)
- Face cards (J, Q, K): 12 (3 per suit)
- Aces: 4
- Each suit: ace, 2-10, jack, queen, king

**For Two Dice** (36 outcomes, shown as ordered pairs (a, b)):
- Sum possibilities: 2 (1 way), 3 (2 ways), 4 (3 ways), ..., 7 (6 ways), ..., 12 (1 way)
- Doubles: 6 outcomes {(1,1), (2,2), ..., (6,6)}
