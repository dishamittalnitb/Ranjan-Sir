# Chapter 37: Statistics (Class X)

## Concept Summary

This chapter develops statistical measures for grouped data:

1. **Mean of Grouped Data**:
   - **Direct Method**: Mean = (Sigma f_i * x_i) / (Sigma f_i), where x_i is the class mark
   - **Assumed Mean Method**: Mean = a + (Sigma f_i * d_i) / (Sigma f_i), where d_i = x_i - a
   - **Step Deviation Method**: Mean = a + [(Sigma f_i * u_i) / (Sigma f_i)] * h, where u_i = (x_i - a)/h

2. **Median of Grouped Data**:
   - Median = l + [(n/2 - cf) / f] * h
   - Where l = lower limit of median class, n = total frequency, cf = cumulative frequency of class preceding the median class, f = frequency of median class, h = class size

3. **Mode of Grouped Data**:
   - Mode = l + [(f_1 - f_0) / (2f_1 - f_0 - f_2)] * h
   - Where l = lower limit of modal class, f_1 = frequency of modal class, f_0 = frequency of class preceding modal class, f_2 = frequency of class succeeding modal class, h = class size
   - Bimodal situations to be avoided.

4. **Empirical Relationship**: 3 Median = Mode + 2 Mean (approximate, for moderately skewed distributions)

## Key Formulas/Theorems

**Class Mark**: x_i = (Upper Limit + Lower Limit) / 2

**Mean (Direct)**: x-bar = (Sigma f_i * x_i) / (Sigma f_i)

**Mean (Assumed Mean)**: x-bar = a + (Sigma f_i * d_i) / (Sigma f_i)

**Mean (Step Deviation)**: x-bar = a + [(Sigma f_i * u_i) / (Sigma f_i)] * h

**Median**: l + [(n/2 - cf) / f] * h

**Mode**: l + [(f_1 - f_0) / (2f_1 - f_0 - f_2)] * h

**Cumulative Frequency**: Running total of frequencies -- used to draw ogive and find median.
