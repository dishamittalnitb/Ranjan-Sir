# Chapter 28: Arithmetic Progressions (Class X)

## Concept Summary

This chapter introduces sequences with a common difference:

1. **Motivation**: Patterns like 2, 4, 6, 8, ... or savings with fixed monthly deposits, etc.

2. **Definition**: An Arithmetic Progression (AP) is a list of numbers in which the difference between consecutive terms is constant, called the common difference (d).

3. **General Form**: a, a + d, a + 2d, a + 3d, ... where a is the first term and d is the common difference.

4. **nth Term of an AP**:
   - a_n = a + (n - 1)d
   - Also called the general term.

5. **Sum of First n Terms of an AP**:
   - S_n = n/2 * [2a + (n - 1)d]
   - Alternatively: S_n = n/2 * (a + a_n)  [when last term known]

6. **Applications**: Daily-life problems involving AP (savings, installment payments, seating arrangements, distance traveled, etc.).

## Key Formulas/Theorems

**nth term**: a_n = a + (n - 1)d

**Sum of n terms**: S_n = n/2 * [2a + (n - 1)d]

**Sum with last term**: S_n = n/2 * (a + l), where l is the last term.

**Common difference**: d = a_2 - a_1 = a_3 - a_2 = ...

**Finding n from last term**: n = [(l - a)/d] + 1
