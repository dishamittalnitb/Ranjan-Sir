# Chapter 22: Statistics - Mean, Median, Mode [FORMATIVE ONLY]

## Concept Summary

This formative-only topic introduces measures of central tendency for ungrouped data:

1. **Introduction to Statistics**: Collection of data, presentation of data in tabular form, ungrouped data vs. grouped data.

2. **Mean (Arithmetic Mean)**: Sum of all observations divided by the number of observations.
   - For ungrouped data: Mean = (Sum of all observations) / (Number of observations)
   - Also denoted as x-bar (x with a bar)

3. **Median**: The middle value when data is arranged in ascending or descending order.
   - For odd n: Median = value at position (n+1)/2
   - For even n: Median = mean of values at positions n/2 and (n/2)+1

4. **Mode**: The value that occurs most frequently in the data set.
   - A data set may have one mode (unimodal), more than one mode (bimodal/multimodal), or no mode.

5. **Range**: Difference between maximum and minimum values = Max - Min.

## Key Formulas/Theorems

**Arithmetic Mean**: x-bar = (x1 + x2 + ... + xn) / n = (Sigma xi) / n

**Median** (ungrouped data):
- Arrange data in ascending order
- If n is odd: Median = (n+1)/2 th observation
- If n is even: Median = [n/2 th obs + (n/2 + 1) th obs] / 2

**Mode** (ungrouped data): The observation with the highest frequency.

**Range**: Max value - Min value
